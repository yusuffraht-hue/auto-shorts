# Daily generation contract

Generate a source project only: distinct gameplay archetype, original hook, Rojo mapping, server/client Luau, metadata, README and test plan. Server owns all progress and rewards. Offline tests must pass before artifact upload.

Never use Roblox credentials, publish, upload to Roblox, spend Robux, add paid APIs/assets, copy other creators' work, or grant client authority over rewards. Require human Roblox Studio play-testing before any sharing or publishing.
